# 82-0

Stell deine Starting Five aus echten Gehältern zusammen – schaffst du die perfekte Saison?

- Spielen: https://dabvud.github.io/82-0/
- Entwicklung: `npm install`, `npm run dev`, `npm test`
- Spielerdaten neu bauen: `node scripts/fetch-sources.mjs` (lädt Stats), dann `npm run data:build`
- Schwierigkeit prüfen: `npm run calibrate`

Stats: Basketball-Reference-Daten über github.com/sumitrodatta/bball-reference-datasets. Gehälter: ESPN (ab 2000/01) und recherchierte Quellen (data/manual/contracts-pre2000.json).
